# Velocity Rush 3D

An offline-friendly Godot 4.4.1 arcade racing prototype with procedural 3D cars/city, chase and cockpit camera modes, touch steering, a virtual steering-wheel control, nitro, brake, and bundled synthesized audio effects.

Open `project.godot` in Godot 4.4.1. Android APK export uses `.github/workflows/main.yml`.

Note: vehicle bodies and sound effects in this package are procedural/prototype assets, not licensed photorealistic Ferrari/Toyota models or recordings. For true high-detail production visuals, add licensed GLB vehicle assets and recorded audio.
